Bitcoin Custody Guardian — Install Guide
=========================================

1. Install the APK in this folder (allow "install from this source" when asked).
2. Open the app and tap "Select the model file".
3. Pick this same folder's .gguf model file (or the zip you downloaded, if you
   did not extract). The app verifies it automatically.
4. Done — everything now runs offline, forever.

The app never uses the internet: it does not hold the network permission, so it
cannot phone home even by accident. Your questions never leave this device.
