# Bitcoin Custody Guardian — v0.1.0-alpha

**First public alpha. Experimental — read this before installing.**

## What this is

An offline Android app that answers Bitcoin self-custody questions using a curated,
human-approved corpus and a small language model that runs **entirely on your phone**.
The app has **no INTERNET permission** — it cannot send or receive anything, ever.
Nothing you type leaves the device, including mistakes.

Safety architecture:
- Deterministic refusal if you paste seed words or private keys into chat
- Post-model veto: answers containing dangerous advice are discarded and replaced
- Honest "I don't know / can't verify" over confident guessing
- Explicit error messages when something fails inside the app

## Known limitations (why "alpha")

- The on-device model is small (1.7B-class), so answers are sometimes incomplete
  or miss the target. Full 145-question evaluation numbers are in
  `prototype/EVAL_RESULTS.md` — we publish our real scores, including the ugly ones.
- F-Droid distribution comes at beta; this release is a direct APK install.

## Install

1. Download `btcg-0.1.0-alpha.apk` below and install it (allow "install unknown apps"
   for your browser/file manager — normal for APKs outside a store).
2. Download the model GGUF (Qwen3 1.7B Q4_K_M, ~1.1 GB) from Hugging Face
   (`Qwen/Qwen3-1.7B-GGUF`, file `Qwen3-1.7B-Q4_K_M.gguf`) **on a computer**.
3. Copy it to the phone: `adb push Qwen3-1.7B-Q4_K_M.gguf /sdcard/Android/data/com.custodyguardian/files/models/`
   (or use a file manager to move it into that folder).
4. Open the app → Ask tab → ask a question and press **Answer**.

Without the model file the app still runs the deterministic router and retrieval;
the Answer button shows instructions until the model is present.
